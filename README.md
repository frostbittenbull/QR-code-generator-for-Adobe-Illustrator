# Генератор QR-кода для Adobe Illustrator

## 📥 Лёгкий и мощный скрипт (JSX) для создания векторных QR-кодов прямо внутри Adobe Illustrator.

Больше не нужно вставлять растровые изображения из сторонних сервисов — создавайте корректную векторную геометрию по стандарту ISO/IEC 18004:2015 в один клик.

---

## ✨ Основные возможности

- **8 типов данных на выбор:** URL, e-mail, телефон, SMS, контакт (vCard), календарное событие, географические координаты (geo:), произвольный текст. Скрипт сам формирует нужный формат строки (vCard, iCalendar, geo-URI и т. д.) — просто заполните поля.
- **Кодировка UTF-8:** поддерживается любой текст, включая кириллицу.
- **Автоматический выбор версии:** тип QR-кода (версия 1–40) подбирается автоматически в зависимости от длины и содержимого введённых данных.
- **Выбор уровня коррекции ошибок:** четыре уровня — L (~7%), M (~15%), Q (~25%), H (~30%) — позволяют балансировать между размером кода и его устойчивостью к повреждениям.
- **Гибкое оформление:**
  - настраиваемый цвет модулей (заливка);
  - опциональный фон под кодом с собственным цветом заливки;
  - опциональная обводка фона с выбором цвета и толщины (в мм);
  - точный размер кода в миллиметрах;
  - непрозрачность готовой группы в процентах.
- **Проверка перед генерацией:** кнопка «Проверить» показывает, какие данные будут закодированы, до создания объекта на артборде.
- **Чистая векторная геометрия:** каждый модуль QR-кода — отдельный векторный прямоугольник, пригодный для масштабирования, вырезки и печати любого формата.
- **Умное позиционирование:** код автоматически центрируется по активному артборду.
- **Группировка объектов:** все элементы объединяются в именованную группу «QR-код», внутри которой чёрные модули лежат в подгруппе «Код», а фон (если включён) — отдельным объектом «Фон».

---

## 🛠 Установка

1. Скопируйте файл `QR-code.jsx` в папку скриптов Adobe Illustrator:
   > **Windows:** `C:\Program Files\Adobe\Adobe Illustrator [версия]\Presets\[язык]\Scripts`  
   > **macOS:** `/Applications/Adobe Illustrator [версия]/Presets/[язык]/Scripts`
2. Перезапустите Adobe Illustrator.

---

## 📖 Как использовать

1. Откройте документ в Adobe Illustrator и выберите нужный артборд.
2. Перейдите в меню `Файл → Сценарии → QR-code` (`File → Scripts → QR-code`).
3. В выпадающем списке **Тип данных** выберите нужный тип: URL-адрес, Адрес электронной почты, Телефон, SMS, Контакт (vCard), Календарное событие, Географическое местоположение или Обычный текст.
4. Заполните появившиеся поля ввода для выбранного типа.
5. Выберите **Уровень коррекции** из выпадающего списка (Низкий L / Средний M / Высокий Q / Максимальный H).
6. В блоке **Оформление** настройте:
   - цвет модулей (Заливка модулей);
   - фон (Заливка фона) и, при необходимости, его обводку (Обводка фона) и толщину обводки (Толщина обводки, мм);
   - размер кода в мм (Размер QR-кода, мм);
   - непрозрачность (Непрозрачность, %).
7. При желании нажмите **Проверить**, чтобы увидеть, какая строка будет закодирована.
8. Нажмите **Сгенерировать** — QR-код появится по центру артборда.

---

## ⚙️ Уровни коррекции ошибок

| Уровень | Восстановление данных | Когда использовать |
|---|---|---|
| **L** | ~7% | Чистая печать, идеальные условия |
| **M** | ~15% | Стандартное использование |
| **Q** | ~25% | Код может быть частично закрыт (логотип) |
| **H** | ~30% | Суровые условия, повреждённые поверхности |

---

## ⚠️ Требования

- Adobe Illustrator (протестировано на версиях CC).
- Перед запуском скрипта необходимо открыть хотя бы один документ.
